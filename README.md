# Aniket & Meetali — Wedding Countdown

1. Install Node.js 18+ from https://nodejs.org
2. In this folder run: `npm install`
3. Start the dev server: `npm run dev` (opens at http://localhost:5173)
4. Build for hosting: `npm run build` (output in `dist/`, upload to Netlify, Vercel, GitHub Pages, etc.)

Change the date in `src/App.jsx` (`TARGET`) and the photo in `src/assets/couple.jpg`.
